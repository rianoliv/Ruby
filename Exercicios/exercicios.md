1. aula1 — Calculadora simples

Crie um programa que peça dois números e mostre a soma, subtração, multiplicação e divisão entre eles.

Desafio extra: impeça a divisão por zero.




2. aula2 — Classificador de números

Peça um número ao usuário e informe se ele é positivo, negativo ou zero. Depois, diga se é par ou ímpar.

Pratique: entrada de dados, conversão de tipos e condicionais.




3. aula3 — Sistema de notas

Peça três notas, calcule a média e informe se o aluno foi aprovado, ficou de recuperação ou foi reprovado. Defina os critérios de aprovação que vai utilizar.



Nível 2 — Estruturas de dados e repetição

4. aula4Case — Menu interativo

Crie um menu de terminal com case:
- 1 — Somar dois números
- 2 — Verificar se um número é par
- 3 — Mostrar uma mensagem
- 0 — Sair
O programa deve executar a opção escolhida.




5. aula5Arrays — Cadastro de nomes

Peça ao usuário cinco nomes, guarde-os em um array e depois mostre todos em ordem alfabética.

Desafio extra: permita pesquisar se um nome está cadastrado.




6. aula6Simbolos — Explorando símbolos

Crie um hash que associe símbolos a informações de um aluno, como :nome, :idade e :curso. Mostre os dados na tela e permita alterar uma informação.

Pratique: símbolos, chaves e valores de hashes.




7. aula7Hashes — Estoque de produtos

Monte um hash em que cada produto tenha nome, preço e quantidade. Calcule o valor total do estoque e permita consultar um produto pelo nome.




8. aula8Repeticao — Jogo de adivinhação

O computador escolhe um número de 1 a 20. O usuário tenta adivinhar, recebendo dicas de “maior” ou “menor” até acertar.

Desafio extra: conte as tentativas e permita jogar novamente.




9. aula9EachMap — Relatório de vendas

Crie um array de preços e utilize each para mostrar cada preço. Depois, utilize map para criar um novo array com os preços acrescidos de 10%.

Desafio extra: calcule o faturamento total usando os valores originais.
